=============================

Detailed Breakdown
-----------------
1. Main Entry
   - login_interface(): The entry point of the program. It handles user authentication and directs users to the chatbot interface.
   - Behavior: Prompts for username and password, validates credentials, and allows access to the chatbot interface. Admin mode is triggered for specific usernames (e.g., "admin") and passwords (e.g., "12345").

2. User Authentication
   - Input: Users provide a username and password.
   - Storage Functions:
     - history(name, password): Saves login credentials to login_interface.csv.
     - data_records(name, password): Saves credentials to User.csv.
   - Files:
     - login_interface.csv: Stores login history.
     - User.csv: Stores user credentials.
   - Logic: Allows up to 3 attempts for login. Admin credentials bypass standard validation.

3. Chatbot Interface
   - chatbot_interface(name, botname): The main interface where users interact with the chatbot.
   - loading_screen(name): Displays a loading animation with timed messages.
   - Menu Options: Provides 11 options for interaction:
     - 1. Chat: Engages in conversation using chat_interaction().
     - 2. Simple Calculator: Performs basic arithmetic (calculator_normal()).
     - 3. Complex Calculator: Evaluates mathematical expressions (calculator_complex()).
     - 4. Quiz: General knowledge quiz (quiz()).
     - 5. Fun Chat: Interactive chat with predefined greetings (fun_chat()).
     - 6. Random Fact: Displays a random fact about sonobuoys (dictionary()).
     - 7. Encode/Decode: Encodes/decodes text using a substitution cipher (encode_decode()).
     - 8. Multiplication Table: Generates a multiplication table (creation_is()).
     - 9. Educational Quiz: Math-focused quiz (educational_chat()).
     - 10. Shloka: Displays a random Sanskrit shloka (shlokas()).
     - 11. Exit: Terminates the program.

4. Chat Interaction
   - chat_interaction(name): Core function for conversational interaction.
   - Input Processing:
     - normalize(text): Converts input to lowercase, removes punctuation, and strips spaces for matching.
     - detect_sentiment(text): Identifies positive/negative sentiment based on keyword lists.
   - Response Generation:
     - qa_data: Dictionary mapping normalized inputs to responses (e.g., "hello" -> ["Hello! How can I assist you today?", ...]).
     - keyword_responses: Dictionary for specific triggers (e.g., "joke" -> list of jokes).
   - Chat History:
     - chat_history: List storing up to 10 recent messages (You: or Bot: prefixed).
     - chat_saver(s, name, chat_history): Saves chat history to chat_history.csv with timestamp, user, speaker, and message.
   - File: chat_history.csv stores conversation logs.

5. Utilities
   - Time-Based Greeting:
     - get_time_based_greeting(): Returns greetings based on the time of day (morning, afternoon, evening).
     - greet_user(): Simplified time-based greeting for the interface.
   - Data Structures:
     - qa_data: Extensive dictionary for question-answer pairs across categories (e.g., general knowledge, science, history).
     - keyword_responses: Maps keywords like "joke" or "quote" to lists of responses.
     - chat_history: List for storing conversation history.
   - External Libraries:
     - random: For selecting random responses, facts, or quiz questions.
     - time: For delays in loading screen and program termination.
     - datetime: For timestamps and time-based greetings.
     - csv: For reading/writing to CSV files.
     - re: For regular expression-based text normalization.
     - ast: For safe evaluation of mathematical expressions in complex calculator.

Summary
-------
The chatbot system is a modular Python application with a focus on user interaction, education, and entertainment. It features a robust login system, a versatile chatbot interface with multiple functionalities, and persistent data storage via CSV files. The concept chart above illustrates the hierarchical structure, showing how user inputs flow through authentication, interface selection, and specific functionalities. The system is designed for simplicity and extensibility, with clear separation of concerns between authentication, interaction, and utility functions.

Notes
-----
- The chart is optimized for Notepad with ASCII characters to ensure compatibility.
- The system assumes write permissions for CSV files in the working directory.
- Some functionalities (e.g., weather) are incomplete due to missing API keys.
- The code handles errors gracefully with try-except blocks and input validation.
